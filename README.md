# The Golden Feather Hampers

A simple HTML and CSS website. No JavaScript, no build step, no framework.

## Files (all in one folder)

| File | What it is |
|------|------------|
| `index.html` | Home page |
| `customized.html` | Customized hampers page |
| `corporate.html` | Corporate gifting page |
| `festival.html` | Festival hampers page |
| `style.css` | Styles shared by every page |
| `logo.webp` | Your logo |
| `images/` | Your photos (see below) |

Keep all files together in the same folder, or the styles and logo will not load.

## View it

Double-click `index.html`.

## Put it online with GitHub Pages (free)

1. Create a public repository on GitHub.
2. Upload every file here, with `index.html` at the top level.
3. Settings > Pages > Source: *Deploy from a branch*, branch `main`, folder `/ (root)` > Save.
4. Your site appears at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Editing

- **Colours:** the `:root` block at the top of `style.css`.
- **Hamper names:** edit the `<h3>` of each card in the page files.
- **Contact details:** search for `goldenfeatherhamper@gmail.com`.
